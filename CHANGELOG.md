# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-08-30

### Added
- **Expressive Writing Ritual**: Private digital writing space where text responds to typing dynamics and dissolves upon sealing.
- **Procedural Web Audio**: Real-time procedural audio synthesis for wind, rain, thunder, and pen strokes with zero external audio assets.
- **Weather Dynamics**: Storm intensity, rain splatter physics, and lighting tied directly to typing rhythm.
- **Privacy Architecture**: Zero server storage, zero cookies, verified zero network leakage.
- **Multi-Platform Releases**: Packaged Tauri v2 desktop executable (`Ritual.exe` / `Ritual-Setup.exe`) and web version at [ritual.harryjameschapman.com](https://ritual.harryjameschapman.com).
- **Diagnostics Overlay**: Real-time state graphs and weather controls accessible via `Ctrl+Alt+D`.
